## Not covered

- **Pixel-perfect diff against Herbert's original PDF.** The spec is a content restatement; the visual check is against the current layout and the rendered pages, not a pixel diff.
- **Live click-through of every PDF link.** The annotations are verified with pypdf (destination and rectangle) and the destinations are checked in the source; opening LinkedIn/GitHub/YouTube in a real browser is outside the suite.
- **PDF text extraction in CI.** `pypdf`/`pypdfium2` are local QA tools only; the repo keeps no PDF dependency. The automated test checks the PDF structure and the source text, and the report records the manual PDF text extraction.
- **A4 or other page sizes.** The spec targets Letter; A4 is out of scope.
- **Screen-reader and Word/Docs import behaviour of the PDF.** Not part of the resume acceptance criteria.
